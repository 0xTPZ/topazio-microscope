# Contribuindo

1. Crie um ambiente virtual com Python 3.12.
2. Instale `requirements.txt`.
3. Execute o diagnóstico antes de alterar a captura.
4. Preserve suporte a DirectShow e Media Foundation.
5. Não inclua `.venv`, `dist`, `build`, capturas pessoais ou dados locais.
6. Descreva no pull request como a mudança foi testada com uma câmera UVC.

O projeto é distribuído sob Apache-2.0. Contribuições são bem-vindas sob os termos da mesma licença.
